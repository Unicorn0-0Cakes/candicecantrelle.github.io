# Applying the portfolio rebuild

One commit, delivered as a patch. It applies on top of `3fbed89` (*Add standalone Rubik's Cube timer*), which is the current tip of `main` in your local clone.

I verified it against two fresh clones of the repository: it applies with no conflicts and produces a byte-identical tree.

---

## Apply it

```bash
cd ~/Documents/GitHub/cube_timer/candicecantrelle.github.io

# safety net — a branch to land on, so main is untouched until you say so
git checkout -b portfolio-rebuild

git am portfolio-rebuild.patch
```

`git am` will print a few `trailing whitespace` warnings. They are inside the commit message body, not the code, and are harmless.

## Preview before you push

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Every internal link is root-relative, so it needs to be served rather than opened as a file — `open index.html` will render the page but lose the navigation.

Worth clicking through: the theme toggle at the top right (day and night are two separately authored palettes, not one inverted), `/simulations/`, `/design/`, and `/software/key-to-stl/`.

## Ship it

```bash
git checkout main
git merge --ff-only portfolio-rebuild
git push
rm portfolio-rebuild.patch          # it is not meant to be committed
```

GitHub Pages will rebuild in a minute or two. **`CNAME` is deleted in this commit**, so the site starts serving from `https://candicecantrelle.github.io` — check under *Settings → Pages* that no custom domain is still set there, since that setting lives in the repository configuration as well as in the file.

## If you want to back out

```bash
git checkout main                   # before merging — the branch just sits there
git branch -D portfolio-rebuild
```

Or after merging, `git revert <sha>`. Nothing was deleted destructively: every old page is preserved under `/archive/`, and the full history is intact regardless.

## Two things to decide

**1. Key → STL is filed as a prototype, not a showcase.**
While writing the case study I read `backend/key_processor.py`. The bitting depths are generated with `np.random.uniform`, under a comment reading *"Simplified: vary depth randomly for demo"*, and `/api/generate-stl` in `app.py` carries a `TODO: Implement actual key-to-STL conversion` and writes a placeholder file. The desktop path does produce a genuine silhouette extrusion, and everything around it — four surfaces, licensing, CI, docs — is finished work. But the measurement at the centre is a stub, so the case study says so and the status is *Prototype*. Change it in `data/projects.js` once the bitting extraction lands.

**2. Two Design items were withdrawn.**
The jewellery before/after retouch pair is a **Louis Vuitton** bracelet — a third-party branded product. Retouching it as an exercise is normal, but showing it on a portfolio without context reads as a client engagement. It is off the site; the originals are untouched in `/archive/jewelry/`. Put it back with a line identifying it as a personal exercise if you would like it there.

The "brand DNA" images turned out to be a one-page brand-guideline sheet for your own former studio positioning — logo, Fira Code specimen, three swatches, tagline — largely generated by a brand-kit tool, and advertising a positioning this rebuild retires. It is recorded in the registry as `hidden` with the reasoning in a comment, so the decision is written down rather than lost. Flip `portfolioStatus` to publish it.

## How to add a project later

Everything the site displays comes from one file: `data/projects.js`. Append a record and it appears. Set `portfolioStatus: "hidden"` and it is filtered out at the query layer, before anything can render it — public on GitHub and published on the portfolio stay separate decisions. No page calls the GitHub API at runtime, so renaming or archiving a repository cannot change the shape of the site.

To bring Games into the global navigation once there is a game in it, set `nav: true` on the `games` entry in the `CATEGORIES` array at the bottom of the same file. Nothing else needs to change.
